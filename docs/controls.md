# Steel Command - 钢铁指令
## 游戏操作说明

## 🎮 游戏模式

- **1 Player**: 单人模式
- **2 Player**: 双人合作模式

## 🎨 游戏元素

### 地形类型 🗺️

| 地形 | 描述 |
|------|------|
| **砖块** (Brick) | 可被炮弹破坏 |
| **钢铁** (Steel) | 无法破坏（除非 protection >= 100%） |
| **海** (Sea) | 坦克无法通过（气垫道具可穿越） |
| **树林** (Forest) | 坦克可隐藏，提供掩护 |
| **屏障** (Barrier) | 靠近会伤害坦克，不可被子弹摧毁 |

### 游戏角色 👥

| 角色 | 描述 |
|------|------|
| **玩家坦克** | 可移动、射击、使用技能 |
| **敌方坦克** | 随机移动和射击 |
| **指挥官** | 需要保护，有生命值 |

### 道具系统 🎁

| 道具 | 效果 |
|------|------|
| **Speed Up** | 提升移动速度（+20） |
| **Protection** | 提升护甲（+20） |
| **Fire Speed** | 提升射击速度（+20） |
| **Fire Shell** | 火焰炮弹（可抵挡一次敌方子弹） |
| **Track Chain** | 履带链（免疫屏障伤害，可抵挡子弹，显示履带特效） |
| **Penetrate** | 穿透能力（可抵挡子弹） |
| **Repair** | 修复坦克（恢复1点生命） |
| **Hamburger** | 恢复生命（恢复1点生命，同时恢复指挥官1点生命） |
| **Air Cushion** | 气垫（允许穿越海洋，显示气泡特效） |
| **Shell** | 增加炮管数量（1→2管） |

## ⚙️ 游戏机制

### 关卡系统 📚
- 多个关卡，难度递增
- 每关有固定的敌人和地形布局
- 每关敌方坦克总数：10
- 场上最大敌方坦克数：4

### 属性系统 📊
- **速度**: 影响坦克移动速度（初始40，最大100）
- **射击速度**: 影响炮弹发射频率（初始40，最大100）
- **保护**: 影响受到的伤害和特殊能力（初始40，最大100）
- **生命值**: 最大3点
- **能量值**: 最大3点（用于激光和冲刺技能）
- **炮管**: 1-2管（影响子弹数量）

### 能量系统 ⚡
- **能量恢复**: 每5秒自动恢复1点能量
- **冲刺消耗**: 1点能量
- **激光消耗**: 3点能量（全部）
- **能量不足提示**: 能量不足时显示警告文字（持续2秒）

### 技能系统 🎯

#### 回城技能 (I / Numpad4)
- 持续时间：2秒
- 消耗：无
- 效果：将坦克传送回初始位置
- 可被移动按键打断
- 显示：进度条显示传送进度

#### 冲刺技能 (K / Numpad2)
- 持续时间：0.2秒
- 消耗：1点能量
- 冲刺距离：两个坦克长度
- 显示：冲刺尘土特效
- 撞击效果：
  - 砖块：可撞碎，扣血（根据 protection）
  - 钢铁：protection>=100% 可撞碎，否则死亡
  - 敌方坦克：可撞碎，扣血（根据 protection），增加100分
- 扣血规则：
  - protection < 40%: 扣 2/3 血量
  - protection 40-80%: 扣 1/3 血量
  - protection >= 80%: 不扣血

#### 激光技能 (L / Numpad3)
- 蓄力时间：3秒
- 消耗：3点能量（全部）
- 效果：发射激光束，穿透多个目标
- 动画：能量球蓄力（0-64帧，循环20-64帧）→ 激光发射（循环81-84帧）
- 显示：能量球特效、激光束、相机震动
- 可被移动按键打断
- 命中目标：敌方坦克、子弹、砖块、钢铁、树林、屏障、海洋
- 注意：被激光摧毁的敌人不计入分数

### 天气系统 🌦️

每关进入时随机选择一种天气：

| 天气 | 效果 |
|------|------|
| **无天气** | 正常游戏 |
| **下雨** | 雨滴粒子效果，雨天音效，火焰弹效果减弱 |
| **下雪** | 雪花粒子效果，地滑效果（移动有惯性） |

#### 雪天机制 ❄️
- 坦克移动有地滑效果（惯性）
- 拥有 track_chain 特效时免疫地滑
- 摩擦系数影响减速过程

### 炮管系统 🔫

根据玩家 shells 数量动态切换炮管：

| shells 数量 | 炮管类型 | 同时子弹数 |
|-------------|----------|-----------|
| 1 | 单管炮管 | 1 |
| 2 | 双管炮管 | 2 |

### 特效系统 ✨

#### 低血量烟雾 💨
- 当玩家生命值 ≤ 1 时自动显示
- 烟雾跟随坦克移动
- 生命值恢复后自动消失

#### 履带特效 🦾
- 拥有 track_chain 特效时显示
- 跟随坦克移动，仅在移动时播放动画
- 免疫屏障伤害和雪天地滑

#### 气垫特效 🫧
- 拥有 air_cushion 特效时显示
- 允许穿越海洋
- 泡泡向上飘动效果

#### 冲刺尘土 💨
- 冲刺时显示
- 位于坦克后方，放大2倍
- 冲刺结束后自动消失

#### 能量球特效 ⚡
- 激光蓄力时显示
- 位于炮管前方
- 蓄力阶段：播放0-64帧，循环20-64帧
- 激光阶段：循环81-84帧

#### 相机震动 📷
- 激光发射时触发
- 震动持续时间：0.6秒
- 震动强度：15像素

### 冲刺技能机制 💨

| 撞击目标 | 条件 | 效果 |
|----------|------|------|
| **砖块** | 总是可撞碎 | 扣除玩家 1/3 血条（根据 protection 调整） |
| **铁块** | protection >= 100% | 可撞碎，否则玩家死亡 |
| **敌方坦克** | 总是可撞碎 | 扣除玩家 1/3 血条（根据 protection 调整） |

**扣血规则**（基于 protection）:
- protection < 40%: 扣 2/3 血量
- protection 40-80%: 扣 1/3 血量
- protection >= 80%: 不扣血

### 屏障伤害机制 🛡️

- 靠近屏障（100像素内）会触发伤害
- speed 和 protection 各减少 20（永久减少）
- 2 秒冷却时间
- 拥有 track_chain 特效时免疫伤害

### 特效抵挡机制 🛡️

拥有以下特效时可抵挡一次敌方子弹：
- **fire_shell** (火焰炮弹)
- **track_chain** (履带链)
- **penetrate** (穿透)

中弹后移除对应特效，不扣血

### 碰撞检测 💥
- 基于 Avian2D 物理引擎的精确碰撞
- 敌方坦克AI：随机移动方向，碰撞时自动转向（基于法线方向）
- 每4秒随机转向
- 每0.1秒碰撞冷却

### 动画系统 🎬
- 丰富的精灵图动画效果
- 包含坦克移动、炮弹飞行、爆炸、烟雾、火花等动画
- 支持三种动画模式：循环、一次性、一次性后循环
- 统一的动画计时器系统

### 敌方坦克类型 🤖

| 类型 | 速度 | 生命值 | 子弹速度 |
|------|------|--------|----------|
| **普通型** (Normal) | 200 | 2 | 900 |
| **火力型** (Fire) | 200 | 2 | 1800（2倍） |
| **重型** (Heavy) | 200 | 4 | 900 |
| **轻型** (Light) | 400（2倍） | 1 | 900 |

### 敌方AI行为 🎯
- 随机移动方向（4个基本方向）
- 碰撞时自动转向（基于碰撞法线）
- 定期随机转向（每4秒）
- 随机射击（3%概率/帧）
- 旋转平滑过渡（0.8秒）

## 🗺️ 关卡编辑器

### 功能概述 🎯

关卡编辑器是一个可视化的地图编辑工具，允许玩家通过点击的方式创建自定义关卡地图。支持14种地形类型，包括全块和半块地形，可以实现精细的地图设计。

### 进入编辑器 🚀

在主菜单界面选择"关卡编辑器"选项即可进入（仅支持非Web平台）。

### 界面布局 🎨

编辑器界面分为以下区域：

#### 中央编辑区
- **网格系统**：12行×16列的白色网格线
- **地图区域**：1600×1200像素的编辑区域
- **实时预览**：放置地形后立即显示效果

#### 左侧地形面板（7种）
1. 空地
2. 海
3. 树林
4. 屏障
5. 钢铁
6. 钢铁上半
7. 钢铁下半

#### 右侧地形面板（7种）
1. 钢铁左半
2. 钢铁右半
3. 砖块
4. 砖块上半
5. 砖块下半
6. 砖块左半
7. 砖块右半

#### 信息显示区
- **右上角**：当前选择的地形图标、文件名输入
- **左上角**：操作提示

### 操作方式 🖱️

| 操作 | 说明 |
|------|------|
| **鼠标左键点击地形按钮** | 选择要放置的地形类型 |
| **鼠标左键点击网格** | 在网格中放置当前选中的地形 |
| **数字键 0-9** | 输入导出文件名（最多3位） |
| **Backspace** | 删除文件名的最后一个字符 |
| **S 键** | 导出关卡文件到 `levels/` 目录 |
| **ESC 键** | 退出编辑器，返回主菜单 |

### 地形类型说明 📐

#### 全块地形（100×100像素）
| 地形 | 符号 | 说明 |
|------|------|------|
| 空地 | `.` | 坦克和子弹都可以通过 |
| 树林 | `t` | 坦克可穿过，提供掩护，子弹可穿过 |
| 海 | `s` | 子弹可穿过，坦克不可通过（气垫道具可穿越） |
| 屏障 | `a` | 靠近会伤害坦克，不可被子弹摧毁 |
| 砖块 | `b` | 1发子弹摧毁 |
| 钢铁 | `i` | 不可破坏（protection≥100%可撞碎） |

#### 半块地形（50×50像素）
| 地形 | 符号 | 说明 |
|------|------|------|
| 砖块上半 | `bt` | 1发子弹摧毁 |
| 砖块下半 | `bb` | 1发子弹摧毁 |
| 砖块左半 | `bl` | 1发子弹摧毁 |
| 砖块右半 | `br` | 1发子弹摧毁 |
| 钢铁上半 | `it` | 不可破坏 |
| 钢铁下半 | `ib` | 不可破坏 |
| 钢铁左半 | `il` | 不可破坏 |
| 钢铁右半 | `ir` | 不可破坏 |

半块地形允许创建更精细的地图设计，比如窄通道、不对称的防御结构等。

### 导出关卡 💾

1. 在右上角输入文件名（1-3位数字）
2. 按 **S 键** 导出关卡
3. 关卡文件保存到 `levels/{文件名}.txt`
4. 导出的关卡可以在游戏中直接游玩

### 地图设计建议 💡

1. **出生点布局**：玩家出生点在地图底部，指挥官在顶部
2. **地形搭配**：合理使用砖块和钢铁创建防御结构
3. **半块应用**：利用半块地形创建窄通道和不对称设计
4. **可玩性**：确保地图有足够的战术空间和挑战性
5. **测试验证**：导出后进入游戏测试关卡可玩性

### 技术特点 ⚙️

- **可视化编辑**：所见即所得的编辑体验
- **网格对齐**：自动对齐到100×100像素网格
- **半块支持**：支持50×50像素的精细地形
- **实时预览**：放置地形后立即显示
- **纹理显示**：使用游戏实际纹理预览
- **动画支持**：树林和海洋显示动画效果

### 注意事项 ⚠️

- 仅在非Web平台可用（Linux、Windows、macOS）
- Web端不支持关卡编辑功能（菜单中不显示此选项）
- 文件名必须是数字（1-3位）
- 每个文件导出时会覆盖同名文件
- 编辑器状态下不会保存进度，退出后需要重新编辑
